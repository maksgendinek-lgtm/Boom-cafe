# Boom Cafe Landing

## Временная публичная ссылка (через localtunnel)

Ссылка: https://tame-peas-fail.loca.lt

**Как это работает:**
1. Запущен `npm run dev` — Vite dev server на порту 5173
2. Запущен `npx localtunnel --port 5173` — туннель, который делает localhost доступным из интернета
3. Ссылка работает, пока оба терминала открыты. Как только закроете — ссылка перестанет работать.

Если нужно сгенерировать новую ссылку — просто запустите заново:
```
npx localtunnel --port 5173
